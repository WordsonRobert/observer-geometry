# Observer Geometry

Code for *Observer Geometry: Describing Graph Structure Beyond the Observation
Horizon*.

Observer Geometry characterizes a node by the metric structure that remains
**unobserved** beyond a budget-limited observation horizon. The observer descriptor is

$$\Phi(v) \;=\; \mathbb{E}_{I \sim P}\big[\,\mathcal{J}(v, \mathcal{H}_I(v))\,\big],
\qquad
\mathcal{J}(v, H) \;=\; \sum_{u \in H} e^{-\delta\, d_X(\varphi(v), \varphi(u))},$$

reported normalized by the total mass $\mathcal{J}(v, V)$. The framework is
metric-space agnostic; the instantiation here uses hyperbolic graph embeddings and a
stochastic walk-based observation process. For that process the expected descriptor has
an exact coverage form, $\mathbb{E}[\Phi_K(s)] = \sum_u w_u (1-p_u)^K / \sum_u w_u$, with
$p_u$ the single-trajectory visit probability, and is computed exactly by
`exact_phi.py`. Core properties are mechanized in Lean 4 (`lean/`).

## Analyses

- **Exact descriptor** (`analysis/exact_phi_all.py`). Enumerates all trajectories of path
  probability at least ε (at most 1/ε per length) and returns E[Φ_K] for K = 1..100.
  It agrees with the three-realization Monte Carlo estimate at Spearman ≥ 0.9966 on all five
  graphs (`results/exact_validation.json`).
- **Closer baselines** (`analysis/closer_baselines.py`). Total kernel mass μ(s,V), expected
  hidden count, radius, random-walk accessibility, eccentricity; correlations, partial
  correlations given radius, the decomposition log(1−Φ) = log C(s) − log μ(s,V), and
  reconstruction with random and community-held-out splits.
- **Sensitivity** (`analysis/sensitivity.py`). Rank agreement and headline numbers across
  δ ∈ {0.25, …, 4}, δ = 1/√c, and ε ∈ {1/20, …, 1/200}.
- **Budget laws and value convergence** (`analysis/budget_value.py`). Arbitrary budget
  distributions via the probability generating function; the limit Φ_∞ and the bound
  (1−ε)^K.
- **Hub cap** (`analysis/cap_inertness.py`). The 256-neighbour cap of the vectorized
  simulator has no effect at ε = 1/50: no capped vertex has a transition probability ≥ ε.
- **Growth** (`analysis/growth.py`). Embedded volume growth and the finite-graph crossover
  that replaces the regular-tree threshold.
- **Reconstruction and transfer** (`analysis/reconstruction_plus.py`,
  `analysis/cross_dataset_transfer.py`, `analysis/transfer_heldout.py`).
- **Embedding robustness** (`embedding_ablation/`). Seed floor, encoder × geometry grid,
  curvature, random null; Cora (Monte Carlo Φ) and Citeseer, GO DAG (exact Φ).

## Interpreting results

- Read every correlation against the seed-to-seed noise floor
  (`embedding_ablation/seed_robustness_results.json`, `robust_<dataset>.json`). The floor is
  dataset-dependent: 0.959 on Cora, 0.962 on Citeseer, 0.851 on GO DAG.
- Use `cluster_level`, not `record_level`, intervals for claims about a graph family.
- Φ is normalized by the total mass μ(s,V) everywhere; `reembed.py` also emits the
  unnormalized μ.

## Caveats

- Message passing occurs in the tangent space with a single exponential map at the output,
  not fully manifold-valued aggregation.
- Curvature is selected by grid search over the Lorentz parameter c ∈ {0.25, …, 8}; the
  hyperboloid ⟨x,x⟩ = −c has sectional curvature −1/c. In geoopt 0.5.1 the Lorentz
  exponential map does not propagate gradients into c, so it is not learned.
- GO DAG and STRING-PPI have no native node features; inputs are log(1 + degree) and 63
  i.i.d. N(0,1) features (seed 0). STRING-PPI keeps edges with combined score ≥ 700.
- The GO DAG uses primary term identifiers only (24,129 terms).
- Closeness and harmonic centrality use a 1,000-pivot landmark estimator, and betweenness is
  sampled at k = 1,000, on the three large graphs.
